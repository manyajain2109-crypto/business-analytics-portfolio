Netflix Data Analysis Using SQL

Project Overview

This project explores Netflix movies and TV shows using SQL to identify content trends.

Objectives

* Analyse movies and TV shows.
* Explore release years and genres.
* Investigate country-wise content distribution.
* Generate insights using SQL queries.

Tools

* MySQL
* SQL

Status

In progress.
Key Analysis Questions

This project answers the following business questions using SQL:

1. What are the top 10 movies based on IMDb score?
2. What are the bottom 10 movies based on IMDb score?
3. How many Netflix titles were released in each decade?
4. How many movies and TV shows are in the dataset?
5. Which release years have the highest number of titles?
6. Additional analysis of Netflix content trends.
7. Analysis of content distribution.
8. Average IMDb and TMDB scores by age certification.

Files

* netflix_analysis.sql — Contains all SQL queries used for the analysis.
